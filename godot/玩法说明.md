# 斗战三国 · 虎牢关斗将

横版 1v1 斗将游戏，场景是虎牢关前。有两种模式：

- **单挑斗将**：玩家操控一员武将，对战 AI。
- **观战擂台**：两员 AI 武将全自动对打。擂主赢了就留在台上，换下一位挑战者，一阵接一阵自动进行。

## 启动

本仓库只有微信小游戏这一支，两种运行方式：

| 方式 | 说明 |
|---|---|
| 微信开发者工具 | 导入 `wxgame/` 目录，点「编译」即在模拟器里跑（线上形态，推荐） |
| Godot 4.7 编辑器 | 打开 `godot/` 目录直接运行（改玩法时用；`-- --touch` 可在电脑上模拟触屏） |

Godot 里调试可加参数：`-- --duel --pair=zhaoyun,lvbu`、`-- --touch --duel`、`-- --watch` 等，见文末。

## 操作（单挑模式）

### 微信小游戏 / 手机（触屏）

| 操作 | 动作 |
|---|---|
| 左摇杆 | 移动（推到底 = 疾跑；骑马时推到底 = 纵马） |
| 轻 | 轻击，连按出连招 |
| 重 | 重击，按住蓄力 |
| 挡 | 按住格挡，看准时机按下即拆招 |
| 闪 | 闪避；骑马时按住 = 纵马冲锋 |
| 跳 | 跳，空中按轻/重出跳斩 |
| 绝 | 怒气满时发动绝技 |
| 拼刀 | 连按「轻」「重」角力 |
| 对手放绝技 | 「闪」按钮会闪，点它闪开就是「险避」 |

战斗界面**右上角**（敌方头像正下方）是暂停按钮；观战模式右下角只有「暂停」，倍速和隐藏界面都在暂停面板里调。开场演出点「跳过」可跳过。

### 电脑（键盘 / 手柄）

| 按键 | 动作 |
|---|---|
| WASD / 方向键 | 移动（上下是战场纵深） |
| J | 轻击。连按出连招，打中后才能接下一招 |
| K | 重击。**按住蓄力**：蓄满可破防、挑飞 |
| L | 按住格挡。**在对手兵器落下前一瞬按下就是“拆招”**：对手被荡开、硬直，自己获得反击加成 |
| 空格 | 闪避（有无敌帧，贴身躲开叫“闪”）。骑马时按住空格纵马冲锋 |
| Shift | 疾跑 |
| I | 跳。空中按 J/K 出跳斩 |
| U | 怒气满（“绝”字发亮）时发动绝技 |
| Esc / P | 暂停 |
| 拼刀时连按 J/K | 角力，把对手震退 |
| 对手放绝技时按空格 | 有一次闪避机会，闪开就是“险避” |

手柄也可以用：X 轻、Y 重、B 闪、A 跳、RB 格挡、LB/RT 绝技。

## 观战模式

右下角只有「暂停」一个按钮。点开暂停面板后：

- **观战倍速**：×1 → ×1.5 → ×2（键盘 F 同效）
- **界面显示**：隐藏/显示血条，方便录屏（键盘 Tab 同效）
- **Enter**：跳过开场
- 一阵打完，7 秒后自动开始下一阵。

## 战斗里会出现的名场面

- **开场**：大标题，二将纵马入场，对阵牌，互相通名。宿命对手有专属台词，比如张飞对吕布骂“三姓家奴”。
- **马战**：开局骑马，两马对冲时交错而过记“一合”。纵马冲锋出手，伤害随马速增加。
- **落马**：体力掉到 55% 被打落马下，慢镜头特写。重情义的武将会**下马相陪**步战。
- **拼刀**：双方重招同时撞上，进入黑边特写，看谁力大把对手震退。
- **拆招 / 破防 / 闪 / 破招 / 反击**：每次都有字样提示，并有慢镜头和音效。
- **诈败拖刀**：关羽等武将会佯装败走，对手追来时回身一刀。
- **对峙**：观战时二将拉开距离会进入正反打特写，风沙骤起，随后双双冲锋。
- **绝技**：九员武将各有一套演出。
  - 赵云「七进七出」
  - 关羽「青龙拖刀斩」
  - 张飞「当阳怒吼」
  - 马超「西凉铁骑」
  - 黄忠「百步穿杨」
  - 许褚「虎痴裸衣」
  - 典韦「古之恶来」
  - 吕布「天下无双」
  - 徐盛「百里疑城」
- **残血**：体力掉到 25% 时红边脉动，慢镜头。有一方低于 35% 时换成决战音乐。
- **终结**：“斩”字大印，胜者摆出胜利姿势并喊话。如果是残血翻盘，会额外标注“绝地逆转”。
- **时辰**：每局随机辰时、午时、酉时、黄沙四种光照。

赵云、关羽、张飞、马超、黄忠（弓）、许褚、典韦（双戟）、吕布（方天画戟）、徐盛（枪）。每人兵器不同，招式表、出手速度、攻击距离、AI 性格都不一样。

## 开发者参数（`Godot --path . -- 参数`）

| 参数 | 作用 |
|---|---|
| `--watch` | 直接进观战 |
| `--duel` | 直接进单挑 |
| `--pair=zhaoyun,lvbu` | 指定对阵 |
| `--rounds=2` | 三局两胜 |
| `--preset=chen/wu/you/sha` | 指定时辰 |
| `--sim=100` | 配合 `--headless --fixed-fps 60`，无画面快速模拟 100 场，打印胜率和事件统计 |
| `--touch` | 在电脑上用鼠标模拟触屏（显示摇杆和招式按钮） |
| `--touchtest` | 触屏自检：自动走一遍摇杆/按钮，打印 PASS/FAIL 后退出 |
| `--winsize=2284x1080` | 强制窗口尺寸，复现全面屏/微信的宽屏比例 |
