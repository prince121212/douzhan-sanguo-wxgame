## 0. 先说清楚一件事：改哪里才有效

`wxgame/` 是**导出产物**，武将数据、贴图、脚本全在 `pkg_assets/index.pck.br` 里，`wxgame/game.js` 只是微信适配层（grep 过，里面没有武将数据）。

所以：

```
改 godot/ 源码 → Godot 导出 Web → brotli 压缩 → 替换 wxgame/pkg_assets/index.pck.br → 微信 IDE 重编译
```

直接改 `wxgame/` 里的东西**不会生效**（除 `game.js` 适配层）。

好消息是这套工程是**数据驱动**的：武将名单、属性、台词集中在 `scripts/core/roster.gd`，贴图由 `manifest.json` 按 id 索引，选将界面/随机/擂台都是遍历 `Roster.ids()`。因此加人不需要改战斗核心。
